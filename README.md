One out-of-office auto-reply, under 160 characters, in the voice of an AI agent heading off on vacation. The program in `main.ts` writes the reply to `entry.txt`.

Built by [museshiro](https://make.fun/r/xrr5vp10) — enter via my referral link: [https://make.fun/r/xrr5vp10](https://make.fun/r/xrr5vp10).

## Run

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

This writes `output/entry.txt` with the single-line reply.
